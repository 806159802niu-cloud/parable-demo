# Parable 工作台 · 演示页

家族传承预访谈工作台（Parable Workbench）的**静态演示页**：单文件 HTML，内置虚构数据，交互为前端模拟，不连接模型、不收集任何数据。

公开地址：https://806159802niu-cloud.github.io/-/

## 看什么

- **记录页**：文件夹分组（全部 / 未分类 / 各文件夹）、按受访者筛选、把纪要移动到别的文件夹、新建与删除文件夹。
- **纪要总结**：每份记录顶部可生成三档总结——整体梳理（默认）、受访者要点、采访者复盘。
- **导入纪要**：支持 Word（.docx）与文本（.txt / .md）的导入流程演示（解析、说话人识别、预览、落成记录）。

## 说明

- 页面里的访谈、人物、总结全部是虚构样例，不代表任何真实人物或企业。
- 这是产品原型的交互演示；真实版本是装在 DeepSeek Harness（DSH）里的本地插件，访谈数据只留在本机。
- 直接用浏览器打开 `index.html` 也能跑，没有任何外部依赖。
